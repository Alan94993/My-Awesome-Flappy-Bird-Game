# 🐦 Easy Pixel Flappy Bird

A simple pixel-style Flappy Bird game made with HTML, CSS, and JavaScript.

## 🎮 How to Play

- **Click** or press **Space** to make the bird flap.
- Avoid the pipes.
- Try to get the highest score possible!
- The game is designed to be easier than the original Flappy Bird.

## ✨ Features

- Pixelated graphics
- Custom Flappy Bird character
- Easy gameplay
- Score counter
- Falling animation when the bird dies
- Restart by clicking or pressing **Space**

## 🚀 Running the Game

Open `index.html` in your browser.

### VS Code

You can also use the included `.vscode/launch.json` configuration and press **F5** to launch the game.
